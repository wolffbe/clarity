# Clarity denylist: video and streaming delivery hosts, plus DoH resolvers.
#
# For NextDNS: paste the domains under Denylist (one per line, without the
# comments) and enable "Block Bypass Methods" under Privacy/Settings, which
# blocks DoH resolvers, proxies and VPN discovery wholesale. NextDNS blocks
# each domain AND all subdomains. The Logs tab shows what an app resolves
# on the real phone; tune the list from there.
#
# For AdGuard Home: same domains as custom rules in the form ||domain^
#
# Blocking works at the granularity of "which server", never "which file",
# because traffic is encrypted. That is enough to cut video CDNs while
# leaving audio CDNs alone, since they are usually separate hosts. If a
# service ever serves both from one host, domain filtering cannot separate
# them.
